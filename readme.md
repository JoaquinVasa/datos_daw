# Práctica RA5 · c+d — Big Data e IA

## 1) Caso
- Sistema: Netflix
- Contexto: Recomendación personalizada de series y películas a los usuarios

## 2) Conceptos
- Big Data: Grandes volúmenes de datos generados por los usuarios
- Análisis de datos: Proceso de estudiar los datos para encontrar patrones
- Machine Learning: Algoritmos que aprenden de los datos automáticamente
- Deep Learning: Tipo avanzado de ML que usa redes neuronales
- IA: Sistema que usa esos modelos para tomar decisiones

## 3) Relación
- Los datos se recogen (Big Data), se analizan, se usan para entrenar modelos (ML/DL) y la IA toma decisiones

## 4) Pipeline
- Datos → Procesamiento → Análisis → ML/DL → IA → Recomendación

## 5) 5V del Big Data
- Volumen: Millones de datos de usuarios
- Velocidad: Datos en tiempo real
- Variedad: Visualizaciones, búsquedas, valoraciones
- Veracidad: Datos generalmente fiables
- Valor: Mejorar la experiencia del usuario

## 6) Ejemplo aplicado
- Datos: Historial de visualización y búsquedas
- Análisis: Identificación de gustos y patrones
- Modelo: Algoritmos de recomendación (ML/DL)
- Decisión: Sugerir contenido personalizado

## 7) Tabla
| Concepto | Función |
|----------|--------|
| Big Data | Recoger datos masivos |
| Análisis | Encontrar patrones |
| ML/DL    | Aprender de los datos |
| IA       | Tomar decisiones |

## 8) Diagrama
Usuario → Datos → Big Data → Análisis → ML/DL → IA → Decisión

## 9) Problemas
- Problema 1: Datos incorrectos (cuentas compartidas)
- Solución 1: Uso de perfiles individuales
- Problema 2: Sesgo en recomendaciones
- Solución 2: Introducir variedad en el algoritmo
